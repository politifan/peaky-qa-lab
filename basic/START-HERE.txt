Peaky Minds. Базовый тестировщик. Дополнение 26.10.2026

Распакуйте архив целиком. Папка student содержит requirements.txt, lab, tests и exercises. Откройте student в Проводнике, в адресной строке введите powershell и нажмите Enter. Рабочая папка должна содержать requirements.txt. Для Python 3.12 создайте среду:
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt

В Linux/macOS используйте python3.12 -m venv .venv, затем .venv/bin/python. Активация не нужна. Далее python означает именно этот полный путь.

До первой локальной практики достаточно вопросов и кодового редактора Stepik. Первая среда нужна в уроке «Среда и первые проверяющие программы». В первой работе счётчики результатов проверяют обработку JSON, а не реальную регистрацию клуба. Основной сервис tickets появляется в HTTP-модуле.

Сервер из student:
python lab/configure.py none
python -m uvicorn lab.app:app --host 127.0.0.1 --port 8000
В другом терминале той же папки student:
python lab/network_smoke.py http://127.0.0.1:8000
Ctrl+C останавливает только свой сервер. Owner — учебная метка, не защита реальных клиентов. Только localhost и синтетические данные.

configure.py меняет lab/fault.json. Уже работающий сервер нужно остановить и запустить заново. Режимы validation/retry/storage/isolation включают по одному. Между разными опытами сохраняйте данные и выбирайте новый учебный файл/метку; для проверки рестарта, наоборот, используют тот же файл в одном сценарии. Не удаляйте qa.sqlite, чтобы скрыть потерю записи.

Рабочий отчёт может быть TXT/Markdown или DOCX. Нужны правило, версия, вход, expected/actual, свидетельство, вывод и возврат. Повторять один DOCX на каждую короткую команду не требуется. DOCX материалов редакции 2 — справочная копия; текущий порядок и уточнения смотрите в Stepik и этом файле. Преподавательская проверка и External Grader не подключены; Stepik проверяет отдельный ответ, локальный сервис — ваша самостоятельная практика.
