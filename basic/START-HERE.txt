Рабочая папка ZIP называется student, в репозитории это basic.
Первые девять уроков: откройте manual/index.html браузером. Python, Docker, аккаунт и сервер не требуются. Продукт один — Клуб Север. Сначала none, затем отдельная учебная сборка с дефектом. Версия видна на странице.
Порядок: правило → ожидание → действие → наблюдение → различающий повтор → короткий вывод. Отчёт notes.txt/Markdown достаточен. Файлы остаются у вас; соседние задачи Stepik проверяют отдельный ответ.
У каждой сборки отдельный ключ localStorage. Если браузер запретил хранилище, фиксируйте blocked и причину. Не очищайте весь профиль и не ожидайте переноса черновика между сборками. Для поддерживаемого HTTP-доступа можно использовать готовый Python http.server; это команда запуска, не программирование.

HTTP-модуль: запускаете готовый сервер, писать его код не нужно. Установите Python 3.12, откройте PowerShell из student:
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe lab/configure.py none
.venv/Scripts/python.exe -m uvicorn lab.app:app --host 127.0.0.1 --port 8000
В браузере http://127.0.0.1:8000/docs, Try it out / Execute. POST /tickets принимает owner/key/title; сохраните возвращённый id. GET /tickets/{id} с тем же owner должен вернуть прежний title. Новый key — новое намерение, точный повтор сохраняет id, другой title того же ключа даёт 409. Owner — учебная метка, не готовая аутентификация.
Linux/macOS: python3.12 -m venv .venv, затем .venv/bin/python. Далее python означает полный путь своей venv. Сервер останавливают Ctrl+C в его терминале. Следующую команду не вводят в занятый сервером терминал.

SQL: в Stepik исполняются настоящие SELECT на маленьких таблицах; локальную qa.sqlite можно читать модулем Python 3.12 sqlite3. Не удаляйте БД ради зелёного отчёта. validation/retry/storage/isolation включают по одному через lab/configure.py с перезапуском своего сервера и сохранением прежнего состояния.
Python как язык начинается в отдельном блоке: значение → input/print → строка → if → функция → assert → JSON/цикл → pytest. В exercises отдельные учебные реализации, их дефекты изучают после языка. tests проверяет готовый API, а не все ученические работы.

Финал: один связный комплект проверки службы заявок — контракт, свои тесты, исходный дефект, исправная версия, регрессия, сохранность после нового процесса и ограничения. Старые DOCX редакции 2 справочные; основной порядок — текущие Stepik и этот файл. Формат Word необязателен. Персональная проверка и External Grader не подключены.
